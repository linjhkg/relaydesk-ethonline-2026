# Public source provenance

Prepared September 10, 2026 from the post-kickoff RelayDesk repository. This does not claim that the repository was public earlier.

The export preserves the ordered technical commits, author/committer dates, messages and code. Two files are excluded across its history: `chuangye.md` (unrelated personal financial objectives) and `.openai/hosting.json` (private hosting project binding). The original local history is preserved. Export commit hashes differ because their trees differ; original SHA references in historical documents are not public object IDs.

Technical design discussions, ABI provenance, AI disclosure, tests and dated transaction evidence remain included. No history is backdated or invented. Untracked recordings, dependencies, generated output, credentials and environment files are excluded.

Self-hosting: run `npm ci --ignore-scripts`, `npm run build`, and serve `dist/` on a static host. Private hosting account bindings are not needed to build or test the code.
